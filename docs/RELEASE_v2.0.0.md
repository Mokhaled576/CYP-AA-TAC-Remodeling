# Expanded analyses version 2.0.0

Adds the scientific code and supporting tables for the revised cross-cohort paper, including discovery QC, broad CYP detectability, cellular/spatial Ephx2 diagnostics, blocked spatial prediction, independent four-week endothelial replication, two further mouse RNA cohorts, human covariate sensitivity, early mouse proteomics and three-week lipidomics. Preserves negative and inconclusive results and documents input and reconstruction limits. Supporting_Analyses is a neutral directory name. Journal-specific submission documents and private author/reviewer materials are excluded. Prior versions remain unchanged.

The new version DOI must be verified after Zenodo archives this release. Do not cite the old version DOI as covering the expanded analyses.
