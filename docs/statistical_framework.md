# Statistical framework and interpretation

## Discovery analysis
GSE308859 discovery analyses are descriptive because each condition is represented by a single deposited transcriptomic library. Cells and spatial spots are not treated as independent biological replicates.

Reported detection percentages, expression summaries, module-score changes, Spearman correlations, and R² values describe the deposited data and do not constitute condition-level inferential evidence.

## Validation analyses
GSE155882 and GSE270896 are summarized at the biological-library level. Each analyzed validation comparison contains two Sham and two TAC biological libraries. Given n=2 libraries per group, interpretation emphasizes:
- effect direction
- effect magnitude
- replicate-level directional concordance
- gene evaluability

Strong inferential claims are not based on nominal P values.

## Interpretation boundaries
RNA abundance and transcriptomic program scores do not directly establish:
- CYP enzyme activity
- EET/DHET/HETE concentrations
- metabolic flux
- causal regulation
- estrogen dependence

Spatial correlations are interpreted as co-variation. Broad cell-type-associated transcriptional programs are not equivalent to exact cell fractions or formal deconvolution.
