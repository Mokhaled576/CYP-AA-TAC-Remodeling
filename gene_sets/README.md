# Gene sets

The final focused CYP/AA panel is stored in `priority_CYP_AA_genes.csv`.

Broader analyses use transcriptomic programs representing:
- AA liberation
- COX/prostaglandin
- LOX/leukotriene
- CYP epoxygenase
- CYP omega-hydroxylase
- epoxide hydrolysis
- eicosanoid receptor biology

Contextual programs include:
- TGF-beta
- NF-kB/inflammation
- Nrf2/antioxidant
- hypoxia/HIF
- lipid peroxidation/ferroptosis
- fatty-acid oxidation
- mitochondrial oxidative phosphorylation

The exact frozen member lists used for final analyses should be committed from the analysis workspace before public release.
