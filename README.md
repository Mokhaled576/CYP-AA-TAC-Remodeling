# CYP AA TAC Remodeling

Code and supporting tables for cellular and spatial CYP and EPHX2 expression during cardiac pressure overload across independent cohorts.

Authors: Mostafa K. Abd El-Aziz and Ayman O. S. El-Kadi

## Current expanded work

The expanded analyses are in [Reproducibility_v2](Reproducibility_v2/README.md). The downloadable archives add supporting discovery diagnostics, four mouse/human transcriptomic cohorts, early mouse proteomics and three-week mouse lipidomics to the earlier three-dataset study. See the README there for source inputs, execution order and reproducibility limits. The expanded results distinguish replication, non-replication and assay-specific differences; they do not establish enzyme activity, eicosanoid flux or a treatment mechanism.

The historical discovery preparation scripts, annotations, gene sets and source tables remain in their original directories. Prior release v1.0.1 is preserved at https://doi.org/10.5281/zenodo.22912931 and does not contain the expanded analyses. The all-version DOI is https://doi.org/10.5281/zenodo.22912930. The expanded v2.0.0 archive is verified at https://doi.org/10.5281/zenodo.23525836. Cite this exact version DOI for the current expanded code and tables.

Original project instructions are documented in docs/RUN_ORDER.md. They retain local paths and require adaptation and original processed objects. Neither the historical nor expanded directory is represented as a verified clean-room reconstruction. Raw source studies are available from their original repositories; see the extracted TAC_Public_Expansion/acquisition_manifest.csv.

Journal submission documents and private review materials are excluded. Code remains under the existing MIT license; source datasets remain subject to their original terms.
